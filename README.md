# yardwise-privacy

The privacy policy and support pages for **Yardwise** (`com.cucerenco.yardwise`, iPhone), served by GitHub Pages from `main` at the repository root.

| Page | URL | Used as |
|---|---|---|
| `index.html` | `https://maxe34.github.io/yardwise-privacy/` | the privacy policy URL in App Store Connect and the game's Settings |
| `support.html` | `https://maxe34.github.io/yardwise-privacy/support.html` | the support URL in App Store Connect and the game's Settings |

If these URLs ever move, the game's Settings and the App Store Connect fields move with them: a policy link that 404s is a review rejection.

The policy describes Yardwise 1.0 as planned on 2026-11-02: progress on the device and in the player's own iCloud, Google Analytics for Firebase (milestone 6, not built yet) starting only after consent where the law asks for it, Game Center scores for the Daily Jam and the Weekly (milestone 7, not built yet), no ads, purchases through Apple. Before 1.0 is submitted, check it against what the build actually does. When the game changes any of that (ads, new analytics, a new online feature), the text here is part of the change, and the effective date moves.
